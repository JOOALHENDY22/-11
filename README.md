# yoRosheta 🩺 | منظومة الروشتة الرقمية الذكية الموثقة

منظومة طبية رقمية حديثة وآمنة تربط بين الطبيب المعالج، الصيدلي، والمريض في مساحة عمل موحدة تمنع أخطاء قراءة خط اليد وتوفر حماية كاملة عبر كود RX مشفر ورمز QR سريع، مع لوحة تحكم سرية للإدارة المركزية.

---

## ✨ المميزات الرئيسية
- 👨‍⚕️ **بوابة الطبيب**: تحرير روشتات رقمية، فحص التعارضات والحساسية، توليد كود الـ RX والـ QR فورياً.
- 💊 **محطة الصيدلي**: استرجاع الروشتة المعتمدة بكود الـ RX أو مسح الـ QR وصرف الأدوية وتسجيل أرقام التشغيلات بأمان.
- 📱 **محفظة المريض**: بطاقة مرور رقمية عالية الدقة لمتابعة مواعيد وجرعات الأدوية.
- 🛡️ **بوابة الإدارة المركزية (SuperAdmin)**: موافقة واعتماد الأطباء والصيادلة الجدد، إيقاف/تفعيل الحسابات، ومراقبة سجل العمليات.
- 🔒 **حماية وأمان عالي**: تشفير كلمات المرور بـ SHA-256 مع Dual Salt، وحماية ضد محاولات الاختراق (Rate Limiting).
- 🌓 **دعم الوضع الليلي والفاتح**: تصميم عصري متكامل مع اللغتين العربية والإنجليزية.

`ash

cp .env.example .env

`

---

## ☁️ النشر على Vercel (Deployment)

1. ارفع المشروع إلى مستودع **GitHub**.
2. افتح حسابك على **[Vercel](https://vercel.com)** واضغط على **Add New Project**.
3. اختر مستودع الـ GitHub الخاص بالمشروع.
4. في خانة **Environment Variables** أضف المتغيرات التالية:
   - VITE_SUPABASE_URL
   - VITE_SUPABASE_ANON_KEY
5. اضغط على **Deploy** وستعمل المنظومة مباشرة!

---

## 🗄️ إعداد قاعدة البيانات (Supabase)
1. انسخ محتويات ملف supabase_setup.sql.
2. افتح مشروعك في **Supabase Dashboard** -> **SQL Editor**.
3. الصق الكود واضغط **Run**.
